# IMT-131nataliaUrzagaste

## Programación Superior
La materia de **Programación Superior** está orientada al desarrollo de habilidades avanzadas en entornos de programación y microcontroladores.
En este curso se trabaja con el sistema operativo **Ubuntu**, aprendiendo su manejo desde la terminal

### Objetivo
Tiene como objetivo introducir lenguajes y entornos de programación específicos para el desarrollo de **firmware y software**

### Competencia de la Asignatura
Implementar algoritmos sobre entornos de desarrollo para aplicaciones de sistemas embebidos.
